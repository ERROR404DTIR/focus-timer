# Focus Timer

A tiny Pomodoro timer in **one HTML file**. No build step, no dependencies, works offline.

**Live demo:** https://error404dtir.github.io/focus-timer/

## Features

- Focus (25), short break (5) and long break (15) modes
- Animated progress ring, accurate even in background tabs
- Sound alert when a session ends
- Daily completed-sessions counter (saved in localStorage)
- Keyboard: `Space` to start/pause
- Tab title shows the remaining time

## Use it

Open `index.html` in any browser, or visit the live demo above.
